# Python-calculator-project
This is a beginner-friendly Python console application that performs basic arithmetic operations. The program allows users to input two numbers and choose an operation from addition, subtraction, multiplication, or division.
It is designed with error handling and looping control so users can continue performing calculations until they decide to exit.

🔹 Features

Addition, Subtraction, Multiplication, and Division

Handles invalid numeric inputs with error messages (ValueError)

Detects invalid operation choices

Loop-based interaction – user can perform multiple calculations without restarting the program

Exit option with user confirmation

🛠️ Technologies Used

Python 3

📂 How to Run

Clone the repository:

git clone https://github.com/your-username/simple-calculator.git
cd simple-calculator


Run the program:

python calculator.py
